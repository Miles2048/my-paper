你这个“创新点一”可以概括成一句话：

**针对复杂城市环境下 RSSI、AOA、PDR 等多源观测可靠性动态变化的问题，本文把融合权重分配建模为强化学习序列决策问题，并进一步提出物理感知 PA-DQN 方法，实现对多源定位结果的自适应加权融合。**

核心不是“用了 Q-learning”，而是：**用 Q-learning/DQN 学习什么时候该相信 RSSI、什么时候该相信 AOA、什么时候该更多依赖 PDR。**

**1. 为什么这里适合用 Q-learning**

你的定位融合不是一次性静态加权问题。因为目标在运动，城市环境中还会有遮挡、多径、NLOS 切换，导致三类信息源的可靠性一直变：

- RSSI：受路径损耗、多径、遮挡影响大；
- AOA：几何约束强，但反射路径会造成角度偏差；
- PDR：短时连续性好，但会累积漂移。

所以权重 \(\omega_t=[\omega_t^{RSSI},\omega_t^{AOA},\omega_t^{PDR}]\) 不能固定。它应该随时间动态调整。

Q-learning 正好解决这种问题：  
在每个时刻，智能体观察当前状态 \(s_t\)，选择一个动作 \(a_t\)，比如增加 RSSI 权重、降低 AOA 权重，然后根据新的定位误差获得奖励 \(r_t\)，不断更新状态-动作价值 \(Q(s,a)\)。

基本更新公式是：

```tex
Q(s_t,a_t) \leftarrow Q(s_t,a_t)
+
\alpha
[
r_t+\gamma \max_a Q(s_{t+1},a)-Q(s_t,a_t)
]
```

意思是：  
当前动作好不好，不只看这一步误差有没有变小，还要看它对后续轨迹定位效果有没有帮助。

**2. 你论文里的 RL-IFA 是 Q-learning 基线**

你先设计了一个基础方法 RL-IFA。它的作用是证明：**强化学习确实可以用于多源定位权重自适应调整。**

RL-IFA 里：

状态是当前融合误差：

```tex
s_t = round(100 \varepsilon_t)
```

也就是把连续定位误差离散成 0 到 100 的状态。

动作是 9 个离散动作：  
对 RSSI 权重和 AOA 权重分别执行“增加、减小、保持”，PDR 权重由归一化约束自动得到。

奖励函数主要和误差倒数有关：

```tex
r_k =
100, e_k=0
round(100/e_k), 0<e_k<1
-100, e_k>=1
```

误差越小，奖励越大；误差超过阈值，就给负奖励。

这套方法的逻辑很清楚：  
**如果某种权重调整让定位误差变小，Q 值就提高；如果让误差变大，Q 值就下降。训练多轮之后，智能体就学会在不同误差状态下选择更合适的调权动作。**

**3. 但 RL-IFA 的问题也正好引出你的创新**

RL-IFA 有三个明显局限，这也是你创新点成立的关键：

第一，它只看后验误差。  
也就是说，系统必须等定位已经错了，才知道当前权重不好。这更像“事后修正”。

第二，它的动作比较粗。  
直接增加、减小、保持权重，容易造成相邻时刻权重跳变，从而让轨迹出现抖动或折线化。

第三，表格式 Q-learning 不适合高维连续状态。  
如果把 RMS 时延扩展、RSSI 方差、几何一致性等物理特征都加入状态，Q 表会迅速膨胀，难以训练。

所以你后面提出 PA-DQN。

**4. PA-DQN 相比 Q-learning 的真正创新**

PA-DQN 可以理解为：  
**用 DQN 替代表格式 Q-learning，并把状态从“误差反馈”升级为“物理感知状态”。**

你的状态向量是：

```tex
S_t=[
\sigma_{\tau,t},
\sigma^2_{RSSI,t},
D_{RF-PDR,t},
\omega_{t-1}
]^T
```

含义分别是：

- \(\sigma_{\tau,t}\)：RMS 时延扩展，反映多径复杂度；
- \(\sigma^2_{RSSI,t}\)：RSSI 方差，反映信号功率波动；
- \(D_{RF-PDR,t}\)：无线定位结果和 PDR 结果之间的几何一致性；
- \(\omega_{t-1}\)：上一时刻权重，保留历史决策信息。

这样智能体不是等误差出现后再调权，而是可以提前感知环境变差。比如 RMS 时延扩展变大，说明多径增强；RSSI 方差变大，说明功率观测不稳定；RF 与 PDR 差异变大，说明不同信息源开始不一致。此时 PA-DQN 可以提前降低不可靠观测的权重。

动作方面，你把粗粒度调权改成离散增量动作：

```tex
\Delta \omega_t^x \in \{-\Delta,0,+\Delta\}
```

这仍然保留 DQN 适合处理的离散动作形式，但每次只小幅调整权重，因此轨迹更平滑。

奖励函数也比 RL-IFA 更适合连续定位：

```tex
r_t = -\varepsilon_t
-
\lambda ||\omega_t-\omega_{t-1}||_2
```

它同时考虑两件事：

- 定位误差要小；
- 权重变化不要太剧烈。

所以 PA-DQN 学到的是兼顾精度和稳定性的融合策略。

**答辩时可以这样说**

本创新点不是简单将 Q-learning 套用于定位问题，而是将复杂城市环境下多源观测的动态可信度变化抽象为马尔可夫决策过程。本文首先构建 RL-IFA 基线，通过表格式 Q-learning 验证强化学习调权的可行性；在此基础上，针对后验误差反馈滞后、离散动作粗糙和 Q 表难以处理高维状态的问题，进一步提出 PA-DQN。该方法引入 RMS 时延扩展、RSSI 方差、RF-PDR 几何一致性和历史权重作为物理感知状态，并采用深度 Q 网络学习状态到调权动作的长期价值映射，从而实现更具前瞻性和平滑性的多源自适应融合定位。
