# 第三章实验结果参考图说明

本目录中的实验结果图由 `generate_ch3_experiment_result_figures.py` 使用 Python 生成。数据为按论文设定构造的可复现实验参考数据，用于确定图形形式、指标量级和预期趋势；正式论文应替换为真实实验统计值。

| 权重分量 | MAE | RMSE | 相关系数 |
